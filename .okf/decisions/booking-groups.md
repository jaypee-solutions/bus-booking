# Booking groups

Use Booking group / Nutzergruppe for TSV sections and approved outside organizations. New bookings
select exactly one active group; deactivation prevents new selections without detaching the group
from history. This avoids misclassifying schools and community organizations as TSV departments.
See `docs/PRD.md` and `docs/adr/0002-booking-groups.md`.
